# Booking App for Auto Services (SaaS)

**Telegram Mini App для автоматизации записи клиентов в автосервисы.** 
Позволяет клиентам записываться на услуги без звонков, а владельцам — управлять расписанием, услугами и получать уведомления о новых записях прямо в Telegram.

## 🚀 Технологический стек

*   **Backend:** Python (Cloudflare Workers), Cloudflare D1 (SQLite)
*   **Frontend:** React, Vite, React Day Picker (для календаря)
*   **Интеграции:** Telegram Bot API, Webhooks
*   **Безопасность:** HMAC-SHA256 (проверка `initData`), CORS, защита от IDOR, валидация данных

## 🏗️ Архитектура и Мультитенантность

Проект построен по принципу **SaaS (Software as a Service)**: один бэкенд и одна база данных обслуживают неограниченное количество автосервисов (тенантов). 

Изоляция данных реализована через поле `tenant_id` во всех таблицах базы данных. Каждый запрос от фронтенда передает `tenant_id`, а бэкенд фильтрует данные, чтобы владелец одного сервиса не мог видеть записи другого.

### Основные таблицы БД:
*   `tenants` — информация об автосервисах (название, адрес, телефон, `owner_telegram_id`, токен бота).
*   `services` — услуги каждого сервиса (название, цена, описание).
*   `schedules` — график работы по дням недели (начало, конец смены, выходные).
*   `slots` — временные слоты для записи (генерируются автоматически на основе графика).
*   `appointments` — записи клиентов (имя, телефон, `telegram_id`, статус, отметка о визите).

## 🔐 Безопасность (Ключевые особенности)

При разработке уделено особое внимание безопасности:
*   **Проверка `initData`:** Бэкенд не доверяет `telegram_id`, приходящему от клиента. Он проверяет криптографическую подпись данных (HMAC-SHA256), которую выдает Telegram, используя токен бота тенанта. Подделать `telegram_id` невозможно.
*   **Защита от IDOR (Insecure Direct Object Reference):** Перед тем как отдать или изменить запись/услугу, бэкенд проверяет, принадлежит ли этот объект тому тенанту, от имени которого действует пользователь.
*   **CORS:** Настроен белый список доменов. Запросы с посторонних сайтов блокируются.
*   **Валидация:** Все входящие данные (цены, телефоны, имена) проверяются на корректность перед записью в БД.
*   **Управление секретами:** Токены ботов и ключи хранятся в зашифрованных секретах Cloudflare и переменных окружения, они не попадают в Git.

## 📦 Установка и запуск (Локально)

### Предварительные требования:
*   Node.js (v18+)
*   Python (3.10+)
*   Установленный `wrangler` (CLI для Cloudflare)

### 1. Запуск Бэкенда:

```bash
cd backend
npm install
# Создайте локальную базу данных (если еще не создана)
wrangler d1 create booking-db

# Примените миграции (находятся в папке migrations/)
wrangler d1 execute booking-db --local --file=./migrations/0001_initial.sql
# ... примените остальные миграции ...

# Запустите локальный сервер
wrangler dev
```
### 2. Запуск Фронтенда:
```bash
cd frontend
npm install
npm run dev
```

Реализованный функционал
Для клиента (через Telegram Mini App):

☑ Просмотр услуг с ценами и описанием.
☑ Выбор даты и времени из доступных слотов (занятые скрыты).
☑ Запись в 3 клика (выбор услуги -> дата/время -> контакты).
☑ Просмотр и отмена своих записей.
Для владельца автосервиса (Панель управления):

☑ Получение мгновенных уведомлений о новых записях в Telegram.
☑ Просмотр записей клиентов по дням недели (календарный вид).
☑ Отметка визитов («Был» / «Не пришел»).
☑ Управление услугами (добавление, редактирование, скрытие).
☑ Настройка графика работы и длительности слотов.
☑ Редактирование информации о сервисе (логотип, адрес, контакты).
